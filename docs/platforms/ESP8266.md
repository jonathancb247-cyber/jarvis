# ESP8266 Integration

Status: Planned

## Overview

ESP8266 support is planned as a future HTTP local node option.

## Current Support

No official ESP8266 firmware is validated yet.

## Possible Architectures

```text
JarvisOS Host
-> HTTP local
-> ESP8266
-> GPIO / Sensor / Relay
```

## Requirements

Future work will likely require:

- ESP8266 board.
- Wi-Fi.
- HTTP server.
- JSON handling within memory limits.

## Recommended Transport

HTTP local is the likely first transport. Memory constraints must be evaluated before official support.
